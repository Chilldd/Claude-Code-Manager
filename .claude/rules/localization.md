# 国际化规范

## UI 语言
- **所有用户可见文案使用中文**，包括但不限于：按钮标签、表单标签、占位符、提示文字、
  弹窗消息、标题、工具提示、状态信息、空状态提示
- **产品名 "cc-manager" 保留英文**，不做翻译
- 技术术语（如 PID、CPU、URL、JSON）保留英文大写形式

## 文案风格
- 简洁、直接，避免生硬的机翻感
- 按钮用词简短（"确定"、"取消"、"删除"、"重试"）
- 提示信息用完整句子，句末带句号
- 工具提示（title）也需翻译

## 动态文本
- 拼接文案保持中文语序，使用模板字符串：
  ```tsx
  `已导入 ${count} 个工作区`
  ```
- 复数处理：中文没有单复数变化，直接用数字 + 名词：
  `1 个会话` / `3 个会话`
